# Векторный поиск

После [установки локальной модели](model.md) создайте зашифрованный индекс с эмбеддингами и выполните поиск:

```sh
hsd index /path/to/documents --output /path/to/search.hsd --model-dir /path/to/model
hsd search /path/to/search.hsd "маяк у моря" --mode vector --model-dir /path/to/model --limit 5
```

Обе команды запрашивают пароль. Для автоматизированного запуска доступен `--password-stdin`. Путь к модели нужен при создании индекса и при векторном поиске; модель не загружается по сети. По умолчанию `search` остаётся лексическим. Сохранённый индекс без эмбеддингов нужно построить заново с `--model-dir`, прежде чем искать по смыслу.

C++ `hsd::VectorIndex` принимает равные по длине массивы фрагментов и векторов, проверяет размерность 384, конечность значений и квадрат L2-нормы в пределах 0,001 от единицы. Неверная пачка не добавляется. Вектор запроса проходит такую же проверку. Поиск сравнивает запрос со всеми векторами скалярным произведением; для нормализованных векторов это косинусное сходство. Возвращаются лучшие `limit` фрагментов, включая путь, диапазон байтов и оценку. При равенстве оценок порядок определяется путём, позициями и порядком добавления. Отрицательная оценка допустима.

Python API `hsd.search.search_encrypted_vectors(index_path, password, query, model_dir, limit=10)` возвращает число фрагментов и результаты C++. Перед поиском HSD сверяет идентификатор локальной модели с сохранённым в индексе. Векторный режим загружает индекс в память и выполняет полный перебор; время поиска растёт вместе с числом фрагментов. Гибридное ранжирование и методика проверки описаны в [оценке поиска](evaluation.md).
