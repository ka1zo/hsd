# Как проверяется качество поиска

Команда `hsd search /path/to/search.hsd "запрос" --mode hybrid --model-dir /path/to/model --limit 5` объединяет результаты поиска по словам и по смыслу. Индекс нужно предварительно создать с `--model-dir`, как описано в [руководстве по модели](model.md). Пароль запрашивается при каждом запуске; в автоматизированной среде используйте `--password-stdin`.

C++ вычисляет BM25 и косинусное сходство, затем строит полные ранжированные списки кандидатов. Итоговый балл — сумма `1 / (60 + ранг)` по каждому списку, где первый ранг равен 1. Документ без словесного совпадения получает только векторную часть. Так объединяются позиции в списках без прямого сравнения разных шкал BM25 и косинуса. Результаты содержат путь, позиции, `bm25`, `cosine` и `rrf`. При равных баллах используется устойчивый порядок по пути, позиции и порядку добавления.

Для повторения оценки установите ML-зависимости, загрузите закреплённую локальную модель и выполните:

```sh
python -m benchmarks.stage8_eval --model-dir models/e5-small --k 3 --repeats 10
```

Набор [`benchmarks/stage8_cases.json`](../benchmarks/stage8_cases.json) содержит 12 вымышленных TXT-документов и 8 запросов с заранее указанными релевантными документами. Скрипт строит временный зашифрованный индекс и очищает его после выполнения. Он выводит средние по запросам Recall@3 и MRR@3, ранги ответов, медиану и p95 времени запроса. Время измеряется после загрузки модели и индекса; для векторного и гибридного режима включает вычисление эмбеддинга запроса и поиск, но не загрузку модели, чтение SQLCipher или построение индекса. Скрипт не обращается к сети.

## Результаты

Таблица для macOS, Ubuntu и Windows находится в [отчёте об измерениях](benchmarks.md). Набор мал и состоит из вымышленных документов: результат показывает работу метрик, но не предсказывает качество на архиве пользователя. В этом наборе гибридный режим повышает полноту относительно поиска по словам и снижает MRR относительно векторного поиска. Задержка зависит от машины, длины запросов и числа фрагментов; полный перебор векторов растёт с размером индекса.
