# Security policy

Please report a suspected vulnerability privately through GitHub's **Report a
vulnerability** option on the repository's Security tab, when available. Do
not put passwords, document content, index files, or exploit details in a
public issue. If private vulnerability reporting is unavailable, contact the
repository owner through their GitHub profile before sharing details.

Supported release status: HSD is currently distributed from source. The CLI
and desktop window use a local SQLCipher index; the source documents remain
under the operating system's normal file permissions. A lost index password
cannot be recovered by HSD. Security fixes will be described in release notes
when tagged releases begin.
