# Changes

## 0.1.0 — First source release

- Search TXT and Markdown files from the command line or desktop window.
- Keep the search index encrypted with SQLCipher and update it when files change.
- Search by words, meaning, or both. Meaning-based search uses a local E5 model that you download separately.

This release is available as source code. It does not include installers or model files. See the [installation guide](docs/install.md) for system requirements and the [security policy](SECURITY.md) for reporting vulnerabilities.
