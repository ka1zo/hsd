# HSD — Hybrid Search for Documents

HSD ищет документы локально: по словам, по смыслу или обоими способами сразу. В проект входят командная строка и настольное окно. Поиск работает на общем C++-ядре, а сохранённые фрагменты и эмбеддинги хранятся в зашифрованном индексе SQLCipher.

Сейчас HSD устанавливается из исходного кода. Готовых установщиков нет. Проверьте требования и шаги для своей системы в [руководстве установки](docs/install.md), прежде чем начинать.

## Быстрый пример

Нужны Python 3.11–3.13, компилятор C++20, CMake 3.20+ и SQLCipher Community Edition 4.x. Автоматические проверки выполняются на Python 3.12. Для создания окружения и установки пакета из корня репозитория выполните:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/hsd --help
```

Затем проиндексируйте папку с документами и выполните поиск:

```sh
.venv/bin/hsd index /path/to/documents --output /path/to/search.hsd
.venv/bin/hsd search /path/to/search.hsd "слова запроса" --limit 5
```

HSD попросит пароль для зашифрованного индекса. Потерянный пароль восстановить нельзя, но индекс можно удалить и создать заново из исходных документов. Без `--output` индекс остаётся временным и удаляется после команды. Для первого запуска подойдут [демонстрационные документы](examples/demo-documents/).

В Windows используйте PowerShell и `.venv\Scripts\python.exe`, `.venv\Scripts\hsd.exe` вместо путей `.venv/bin/`.

## Поиск по смыслу

Векторный и гибридный режимы используют локальную модель E5. Установите ML-зависимости, скачайте файлы модели отдельной командой и добавьте `--model-dir` при индексации и поиске:

```sh
.venv/bin/python -m pip install '.[ml]'
.venv/bin/python -m scripts.fetch_model --dest models/e5-small
.venv/bin/hsd index /path/to/documents --output /path/to/search.hsd --model-dir models/e5-small
.venv/bin/hsd search /path/to/search.hsd "маяк у моря" --mode vector --model-dir models/e5-small
.venv/bin/hsd search /path/to/search.hsd "маяк у моря" --mode hybrid --model-dir models/e5-small
```

Модель занимает около 252 МБ. HSD не скачивает её при запуске или поиске. Лицензия и контрольные суммы файлов приведены в [описании модели](docs/model.md).

## Настольное окно

Установите дополнительные зависимости и запустите окно:

```sh
.venv/bin/python -m pip install '.[desktop,ml]'
.venv/bin/hsd-desktop
```

Для поиска только по словам достаточно `.venv/bin/python -m pip install '.[desktop]'`; модель не нужна. Окно позволяет выбрать папку с документами и файл индекса, ввести пароль и посмотреть найденные фрагменты. В Windows вместо `.venv/bin/` используйте `.venv\Scripts\`. Дополнительные шаги для Windows приведены в [руководстве установки](docs/install.md).

## Разработка

Исходники C++ находятся в `cpp/`, Python-пакет, CLI и настольное окно — в `src/hsd/`, тесты — в `tests/`, документация — в `docs/`. Чтобы собрать и проверить C++-часть:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

На Windows для много-конфигурационной сборки добавьте `--config Debug` к командам сборки и CTest. Python-тесты запускаются из установленного окружения:

```sh
.venv/bin/python -m unittest discover -s tests/python -v
```

Подробнее — в [руководстве разработчика](docs/development.md). Устройство зашифрованного индекса описано в [отдельной заметке](docs/index-format.md), а методика оценки поиска — в [описании проверки](docs/evaluation.md).

## Данные и лицензии

HSD читает файлы `.txt`, `.md` и `.markdown` в выбранной папке. Индекс содержит текст фрагментов, пути и, если используется модель, эмбеддинги. Исходные документы остаются на месте. Поддерживаемые ограничения чтения файлов и токенизатора описаны в [руководстве разработчика](docs/development.md). Шифрование индекса не защищает исходные документы или уже разблокированный компьютер.
